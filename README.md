# 🎨 Multi-Language Custom Programming Language

A custom mini-programming language interpreter built with Python and Tkinter, designed to work smoothly on Android (Pydroid 3). It supports multiple languages (Japanese, English, Vietnamese) so that anyone can learn programming basics intuitively.

## ✨ Features (主な機能)
- **Multi-language keywords**: Support for Japanese, English, and Vietnamese.
- **Commands implemented**: let/保存 (Variables), print/表示 (Output), if/もし (Conditions), loop/繰り返す (Repetition), wait/待つ (Delay).
- **GUI Environment**: Simple code editor with a built-in "RUN" button tailored for mobile screens.

## 🚀 How to Run (動かし方)
1. Install **Pydroid 3** on your Android device.
2. Copy the Python code into the editor.
3. Press the **RUN (実行)** button!

## 💻 Sample Code (サンプルコード)

### Japanese (日本語)
```text
保存 ポイント = 120
もし ポイント > 100 応援 合格！
待つ 1
繰り返す 3 表示 ヤッホー
```

### English (英語)
```text
let score = 120
if score > 100 cheer PASS!
wait 1
loop 3 print Hello
```
